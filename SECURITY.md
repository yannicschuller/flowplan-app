# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately via [GitHub's private vulnerability reporting](https://github.com/yannicschuller/flowplan-app/security/advisories/new).

Include what is affected (iOS, iPadOS or Android, app version shown at the bottom of the app settings), how to reproduce it and the impact you see. You will get an answer within a few days; fixes are released as soon as possible and credited if you wish.

## Supported versions

Security fixes go into the latest build on TestFlight, Google Play and the APK on the releases page. Please keep the app up to date.

## Scope

In scope: this app – the native shell, its offline copy, push notifications, widgets, share and capture extensions, and how it stores sign-in data on the device. Problems in the Flowplan server itself belong to [flowplan](https://github.com/yannicschuller/flowplan/security/advisories/new); the push relay to [flowplan-push](https://github.com/yannicschuller/flowplan-push). If you are unsure, report it here.
